# Multi-Sensor Drone Detection & Tracking Platform

A civilian, defensive, educational platform that simulates, detects, tracks, and
visualizes drone-like moving objects using multiple sensor sources.

Python simulates the world and the sensors; a C++17 engine performs the tracking;
Python analyses and visualizes the results.

> **Status: V0.1 in development.** This README is a placeholder and will be written
> properly once the system exists. See [`docs/`](docs/) for requirements, architecture,
> and design decisions.

## Scope

This project is strictly educational and defensive. It performs detection, tracking,
and estimation only. It does not implement weapon control, fire control, guidance,
interception, or engagement logic, and it will not.
